# Gerayo Demo

Intercity (Kigali ↔ Provinces) bus booking demo for Gerayo, built as a frontend-only React + Vite SPA matching Gerayo's existing dark visual identity.

## Stack

- React 18 + Vite 5
- TailwindCSS 3 (Gerayo dark theme)
- react-leaflet (OpenStreetMap, dark tiles)
- qrcode.react (ticket QR codes)
- Mock data + localStorage (no backend)

## Run

```
npm install
npm run dev
```
